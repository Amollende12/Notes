# 📝 Notes App

A simple full-stack Notes App built using **React**, **Vite**, **Node.js**, and **Express**. It allows users to securely log in and manage their personal notes with features like create, edit, delete, and search. JWT authentication is used for user login.

---

## 📖 Description

This project is a basic note-taking application developed to practice full-stack web development. Users can log in, create notes, edit them, delete them, and search through their notes. The frontend is built with React and Vite, while the backend uses Node.js and Express. Notes are currently stored in memory, making this a demo project without a database.

---

## ✨ Features

- 🔐 User Login with JWT Authentication
- ➕ Create Notes
- ✏️ Edit Notes
- 🗑️ Delete Notes
- 🔍 Search Notes
- 🚪 Logout Functionality
- 📱 Responsive User Interface

## 🚀 Installation

### Clone the repository

```bash
git clone https://github.com/Amollende12/Notes.git
```

### Go to project folder

```bash
cd Notes
```

### Install Frontend Dependencies

```bash
cd client
npm install
```

### Install Backend Dependencies

```bash
cd ../server
npm install
```

---

## ▶️ Run the Project

### Start Backend

```bash
cd server
npm start
```

### Start Frontend

```bash
cd client
npm run dev
```

Frontend will run at:

```
http://localhost:5173
```

Backend will run at:

```
http://localhost:5000
```
